Overview

This project is an interactive Power BI Dashboard developed to analyze Adidas sales data and generate meaningful business insights. The dashboard helps in understanding sales performance, profit trends, regional analysis, and product-wise performance using data visualization techniques.

Features:
Sales performance analysis
Revenue and profit insights
Region-wise and state-wise sales analysis
Product category analysis
Monthly and yearly sales trends
Interactive filters and visualizations

Tools & Technologies:
Power BI
Microsoft Excel
Data Cleaning & Visualization

Dashboard Insights:
Identified top-performing regions and products
Analyzed sales trends over time
Compared profit and revenue across categories
Visualized customer and sales patterns effectively
